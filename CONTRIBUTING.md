# Правила изменений MindMap

`main` должен отражать только проверяемую историю. Не собирать пользовательский
архив из произвольной локальной папки.

1. Каждое исправление начинается с воспроизводимого симптома и доказанной причины.
2. Исправление получает регрессионный тест.
3. Версия, README, project-docs и диагностический экспорт должны совпадать.
4. Пользовательская база, диагностика, логи, `.env*`, `node_modules` и generated
   `public/sql-wasm.wasm` не коммитятся.
5. Исторический run нельзя продолжать другой моделью.
6. После ошибки или перезагрузки AI-запрос не повторяется автоматически.
7. Исходный архив создаётся только `npm run package:source` из чистого commit.
